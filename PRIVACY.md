# Privacy and provenance

This public bundle includes only selected storage measurements, relevant firmware code excerpts and generic verification code. Measurement values were retained unchanged. The disassembly's local source filename was replaced with the firmware path `/system/lib64/libc.so`.

Excluded: raw bug reports, full audit logs, account information, order details, personal names and email addresses, device serial numbers and other unique device identifiers, IP/MAC addresses, Wi-Fi details, remote-access IDs and passwords, tokens, signing keys, personal media and local computer paths.

The repository owner's GitHub account remains visible. This is a redacted evidence publication, not an anonymous publication. Git commits use a generic contributor identity.

The supplied files are not a complete forensic image. The original firmware binary, raw logs and original app are not published. The retained excerpts support the stated analysis but do not substitute for independent examination of the original device and firmware.
